Move the current repo into `C:\Development\`, preserving the full working tree, and ensure the local project root is registered there. If the repo already exists elsewhere, copy or re-home it into a matching `C:\Development\<repo-name>` folder and verify the new root. Leave the old copy untouched unless I explicitly ask you to remove it.
