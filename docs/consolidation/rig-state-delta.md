# Independent rig-state demo adoption

The optional private package at `demos/rig-state-assembly` adopts the audited
53-file web/contract packet from the current assembly prototype, including its
required previously untracked UI/store/provider modules. No icons, static
reference assets, native shell, private recovery records, or source archives are
included. Source snapshots and Git preservation remain local and untouched.

The adopted display contract retains 18 states, five display statuses,
deterministic accessible SVG, scenario/evidence views, builder/comparison,
browser SVG/JSON downloads and print presentation. Web-only commands retain
the source dependency closure and lockfile. External Google Font requests and
native save-success stubs have been removed. Reports and telemetry identify
simulated data; invalid numerical/display inputs and incomplete manifests are
rejected before assembly. Generation stays bounded to the demo package.

| Variant / feature | Disposition and benefit | Cost / limitation |
| --- | --- | --- |
| Current componentized prototype | Adopted as the independent web demo; preserves interactive work and testable display semantics | Separate opt-in package, dependency maintenance and browser verification; no desktop integration |
| D monolithic/native variant | Preserved locally as an alternate minimal nine-scenario UI and native toolchain/build reference | Duplicated UI and divergent native manifests/launchers; native build and file export need separate acceptance |
| G static SVG design | Preserved locally: 18 primitives, 18 assemblies, visual families and narrative designs | No supplied regeneration tool or dynamic-renderer parity; assets require provenance and visual review before adoption; excluded here |
| O OOXML design/export source | Preserved locally: editable native-shape document generator and broader experimental context/slot grammar | Incompatible schema and semantics, including FLOW_CHECK flow contradiction, incomplete activity coverage, hard-coded generator lists and unpinned build; no schema or cross-format parity claimed |
| Compound glyph/alarm design | Preserved locally as proposed requirements for Boolean union/subtraction/intersection, silhouettes and alarm lifecycle | Renderer still uses layers and severity rail; no Boolean geometry or alarm reducer; silent audio is intentional |
| Live provider/native export proposals | Provider source remains disconnected; native sources remain preserved locally | Generic WebSocket stub is not WITSML/ETP or a validated integration; no live services, sensor inference, audible alarms or native file save implemented |

Numerical Core remains the single numerical authority. This package accepts a
supplied state ID and evidence; it does not replace the Rust classifier, replay
journal, engine, workbook or desktop contracts. A future adapter requires
explicit source-event provenance, units, timing, missing-channel handling and
direction/context evidence. Demo confidence and thresholds must not be promoted
into engineering assertions. No new physics or field-qualification claim is made.

Print CSS retains the report's ancestors and hides non-report content. DOM/CSS
inspection is not native print-preview, pagination, PDF-export or Office
acceptance. The browser's print capability determines whether Print Report can
complete. Native Excel/add-in acceptance is outside this demo's scope.

Run the demo's tests, typechecks, generator and production build using its README.
Local verification evidence is kept out of public source. These dispositions
authorize no deletion or publication of preserved variants or reference assets.
